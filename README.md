# Doubly-Circular-Linked-List-Using-DotNET-CSharp
This is the simplest implementation of Doubly Circular Linked List data structure using C# .NET. It is a menu driven program that can perform operations on integer values like:

1. Append List
2. Prepend List
3. Insert Into List
4. Display
6. Update Data 
7. Delete from front
8. Delete from rear
9. Delete Element
10. Rotate Forward
11. Rotate Backward
12. Exit
    
What it is and how it is?
A DSA named namespace is created which have DLLNode and DoublyLinkedList public classes. This is to maintain all DSA related classes used in several data structure implementations.

How to run this project?
This repo can be cloned and run using "dotnet run" command on CMD.
